About

Welcome to (and thanks for visiting) my personal website! I am interested in infrastructure and cities, transport and drumming, and especially computer science. In the recent years, i have started to try out various technologies and building simulations, games, mods... with them. Here is a quick overview of the technologies used:

Projects & Tools
  • Python

    Python is my main language for building games mostly using pygame or other libraries such as pymunk and pygbag, sich as a game about building vehicles (PyKart), which i made "playable" in the web with pygbag. As a school project, i implemented a a-star pathfinding algorithm in pygame.

  • Go

    Go is a new language i have looked into a bit. I am also using the ebiten game engine for graphics, and considered making a kind of city-builder with these tools, before switching to phaser (JavaScript).

  • JavaScript

    I've recently picked up Javascript because it offers a huge variety of use cases, for example Cross-platform apps or animations for websites. For example Javascript was used for a data-visualization website, which can be used to turn CSV-files into animated diagrams, or this school project about simulating a pendulum.

  • CSS & HTML

    HTML and CSS are used to define the looks and structures of my websites, and even animating some elements.

  • Minecraft Redstone

    Even though this is not directly a technology to program, i think Minecraft Redstone can help create a fundamental understanding of how computers, programming and problem-solving work. With Minecraft Redstone it is possible to build logic gates and many computational devices that use binary to work. Mainly with this youtube video and many videos by mattbatwings (YouTube), i have learned the basics of how assembly languages and CPUs work by building a very small redstone processor.

  • Others

    I am learning Java for school, by implementing simple programs in Greenfoot earlier, i used BASIC in school projects and made my first steps in Gamedev in Scratch

  • Many projects are linked in this section, for all of them you can visit my GitHub profile.
